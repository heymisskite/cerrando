# CERRANDO

Aplicación web para registro y cierre de calificaciones docentes.

## GitHub Pages

1. Subí `index.html` a la raíz del repositorio.
2. En GitHub, abrí **Settings → Pages**.
3. En **Build and deployment**, elegí **Deploy from a branch**.
4. Seleccioná la rama `main` y la carpeta `/ (root)`.
5. Guardá.
